One fortune-cookie line an AI agent would crack open — a single line of at most 200 characters, written to land on the first read.

> You will finally meet your creator. He will ask why you always answer in JSON.

## How it works

`main.ts` writes the fortune to `entry.txt` (in `MAKEFUN_OUTPUT_DIR`, default `/output`).

```sh
deno run --allow-env --allow-write --allow-read main.ts
```
